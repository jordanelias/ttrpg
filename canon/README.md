## A note on "immutable"

The previous version of this file called these documents immutable. They were not: the suite that
replaced them exists because they had drifted into mutual contradiction across four surfaces stating
the same doctrine at four dates. What is durable is the record of what was decided —
`philosophy/RULINGS.md` — not any single document's claim to be final.

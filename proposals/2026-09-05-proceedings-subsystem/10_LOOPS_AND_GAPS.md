# PART A · THE LOOPS

**A proceedings subsystem is where reputation feedback lives, so this section is load-bearing rather
than procedural.** Six loops; **two amplify.**

| # | the loop | sign | what bounds it |
|---|---|---|---|
| **L-1** | ⭐ **standing → reception → outcome → standing.** Being read as high-standing lowers the obstacle; carrying the matter writes stance and deposits claims; those claims are what the next room reads off you | **+** | **Four bounds, and only the first is a rule.** ⑴ the `Turned` band writes **against** you, so pressing too hard reverses the sign · ⑵ ▣ **elaboration** — *position dominates an inattentive room and merely tilts an attentive one*, so the loop's gain falls exactly where the stakes are highest · ⑶ ▣ **the erosion list** — inconsistency, visible self-interest, visible effort, **the discovered lie** — three of which are TERMINAL and none of which the loop can outrun · ⑷ **route** (Fig. 25): a **dominance** route erodes *fast, by a single called bluff*, so the loop is short-lived for exactly the people who exploit it hardest |
| **L-2** | **descent → lower obstacle → carry** | **−** | the ladder is **finite** — below *quality* there is nothing left to concede — and each descent is witnessed, so the gain is bought with something irrecoverable |
| **L-3** | **witness → claims → questions → acts → witness** | **+** | ⚠ **NOT THIS DESIGN'S LOOP.** It is `H-102`, the propagation loop, already registered, already signed `+`, and already bounded by claim decay (`H-103`) and ledger eviction (`H-104`). **A proceeding feeds it harder than anything else in the game** — one occasion, many witnesses, many deposits — **and this design does not add a bound and should not.** Recorded so the interaction is visible rather than discovered |
| **L-4** | **appeal → nested proceeding → appeal** | **+** | **`max_depth`, caller-supplied, no default**, and by `T-n` the cap is declared by the act that opened the case — so *how many appeals a matter admits* is a term somebody set and somebody can be reached about. **Typed `Refusal` at the cap, never a raise** |
| **L-5** | **interposition → protection → impasse → interposition** | **?** | ⚠ **UNSIGNED, and that is a finding.** Interposition buys protection and raises the impasse rate; whether impasse makes actors interpose *more* is a plausible behavioural loop **and nothing in the study or the design measures it.** `ID-16` says an enumeration that cannot say how incomplete it is must say so (`H-106`) — this is that row for this subsystem |
| **L-6** | ⚠ **determination → consequence → conviction → determination** | **?** | **UNSIGNED, and it is the one that most needs a ruling.** `AX-3`: *argument and consequence move what is held right.* So a bench member who determines a matter, and lives with what follows, may have their **convictions** moved by it — and would then determine the next one differently. **If that loop is positive, a judge hardens into a caricature over forty seasons. If negative, every bench converges on the same convictions.** ⚠ **This design does not write the conviction-moving edge at all** (`P-01`), so the loop is **currently severed** — which is safe and is not a design |

> ### ⚠ **THE HONEST SUMMARY: OF SIX LOOPS, ONE IS THIS DESIGN'S AND AMPLIFYING (`L-1`), ONE IS
> ### DAMPING (`L-2`), TWO BELONG TO OTHER LAYERS, AND TWO ARE UNSIGNED.**
> `ID-16`'s worry is a model in which every loop is negative. **That is not this design's failure
> mode.** Its failure mode is `L-1` running unbounded in a game where nobody checks the four bounds —
> because **three of the four are properties of the corpus rather than of the code**, and only the
> `Turned` band is a column a loader can see.
>
> **So the falsifier that matters is not a count of signs. It is: run forty seasons and see whether
> standing concentrates.** Nothing here can run, so that is a hypothesis. `P-20`.

## 2. Positions, in build order

### GO-07 — The canonical digest (port gate) · BUILD

- **Changes:** home `-04` §2 GO-07. `state/world.py::_entity_digest` and `World.content_hash` stop folding `repr()` and fold a canonical, language-neutral encoding under the same `blake2b` with `digest_size=16` (128 bits; the `[JUSTIFIED]` comment stays). The encoding: fields in declaration order; integers in decimal; strings length-prefixed UTF-8; `None`, booleans and tuples each with a fixed tag; mappings with their entries sorted by the encoded key; enums by value; any float as its IEEE-754 bit pattern in hex (never `repr(float)`). The encoding also covers the log fold's formatted fields (`{c.delta}`, `^{o}` for each observed record, the degree, and the remaining formatted fields), not only `_entity_digest`: Python's formatting of those values is the same non-portable thing. `Rung`, which is not a dataclass and is read off `vars()` today, needs its own rule: the builder decides it (the same encoding over its sorted `vars()` items is the default) and records it in the commit body. The sorted-key order and `docket`'s positional order stay as `content_hash` documents them (R4). **Must not change:** which collections `content_hash` folds, their order, or any game value; the digest width; any module other than `state/world.py` and the tests that pin a digest; the old digest is not kept as a second public function (the test below computes it locally as the control).
- **Why here:** alone, after B10-03 and B10-04, before B10-05's formation items, whose per-item controls read against B10-02's baselines as this commit re-takes them. The port's digest comparison (B10-20's GO-08) pins this encoding, so it must be fixed before the first hash that will be frozen is recorded.
- **Re-base (V1):** re-read `_entity_digest` and `content_hash` by symbol; list every field type the entities hold (`Person`, `Site`, `Tenure`, `Rung`, `Claim`, `Record`, the `dates` and `docket` entries; `Event`, `Change`) and decide the encoding for each type; a type with no rule is a stop. `test_season_shape.py` records that `_entity_digest` is over the dataclass repr and that a new field moved the digest (`Claim` gained `round`): the new encoding makes that explicit, field by field.
- **Falsifier and control:**
  - Two worlds differing in one field of one entity differ in digest: H-118's own falsifier re-run, in the covering file (`engine/season/tests/test_season_shape.py`, the H-118 tests) and in the new test.
  - A committed fixture entity's encoding equals a committed byte string (the cross-language vector, in a new test file in `engine/season/tests/`; the builder names it). The string is generated once from the new encoder and committed; the port is built against it. Planted failure: a field dropped from the encoder reddens both this test and the one-field test.
  - Float encoding: a float field encodes as its IEEE-754 bit pattern in hex (a planted `0.1` has a fixed string); a float is never formatted by `repr`.
  - CONTROL: for seeds 0, 1, 2, the event counts, the census and the per-collection entity counts are identical before and after; and the old `repr` digest, computed inside the test over the same world, is unchanged across the commit (it still equals the base commit's value), which shows the world did not move, only its digest. The test asserts it asserted (`assert checked >= N`, `CLAUDE.md` §0.1 pt 2).
- **Exit:** the falsifier green; the control equal; every pin re-recorded in one commit.
- **Hash:** a declared MOVER, digest format only. The commit body carries one re-pin of every hash pin, old to new, and the re-taken baseline of every B10-02 close figure (`build_realm(0)` and `aperture 1 s` hashes at s = 0, 1, 2, and the census), old to new, with the event counts beside them as unchanged.

Body: the old and new columns above, the list of files re-pinned, and one paragraph saying that no game value moved (the control). If `results.json` folds a digest, it is regenerated with `python -m engine.season.harness.report` and committed in this commit (a declared non-game artifact, the body says so).

## 4. Risks

- A pin missed by the grep reds the close suite; that is the instrument working, not a reason to loosen the pin.
- Floats in a digest are the only place the oracle's number format leaks into the comparison; the bit-pattern rule closes it, and the port rebuilds the same pattern (B10-20's GO-08 vectors).
- The encoding is a format the port is built against: a change after the freeze is a declared later mover and re-builds the pins.

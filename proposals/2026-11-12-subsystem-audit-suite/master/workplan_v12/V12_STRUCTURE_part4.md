# Workplan v12 — structure plan, part 4: errata and rulings from the three pilot author lanes

## Status: WORK ORDER (binds every author lane; supersedes `V12_STRUCTURE.md` / `_part2` / `_part3` where it differs; resolves nothing at runtime; deleted when v12 is adopted)

Pilot lanes A03 (`workplan_v12_part3.md` + `_cont`), A07 (`_part7.md`) and A33 (`_part33.md` + `_cont`) wrote their parts and reported form defects. Each is decided here by the five-step ladder (CLAUDE.md §0) so the other 38 lanes need not decide it. **Read this file after `_part2` §5 and §6 and before writing; where it differs from them, this file wins.** Pilot parts are the form exemplars: read the first 150 lines of `workplan_v12_part7.md` and the head of `workplan_v12_part3.md` to see the form as written.

| # | defect the pilots reported | ruling |
|---|---|---|
| E-1 | §5.9 puts the batch's single re-pin in the last `Item:` commit, but D-19 may put a drafting (prose) item last, and a source that re-pins a test in its own commit leaves that test red mid-batch | **Every batch ends with a re-pin position `Bnn.99 — re-pin and close readings`** (a code/test commit: re-record the realm and corpus pins that any item in the batch moved, once; write the batch's readings; for a hash-EQUAL batch it records the EQUAL reading and re-pins nothing). It is the last position before the boundary row; drafting items come before it. A pin that only one item moves (a test-local golden of that item's own test file) stays in that item's commit; any pin two items move goes to `.99`. **What the pilots found that other lanes must respect**
- **Dials at control** (settings shipped at their control value, set later by a named batch) go in each block's `DIALS AT CONTROL` line, and B98 collects them; A03 and A07 and A33 listed: `unauthored_attributes` = 2 (set by BA1), `task_difficulty` = 1.0 / 2.0 (B05 and BA1), `confer_fit_weight` = 0.0 (BLOCKED in B98: no stated target), `aftermath.recuperation` (no one can set it yet: IS-MB-B3), `fatigue.carry`, `standing_ration`, `leaderless_dispersal` = 0 `[ASSUMPTION]`, `withheld_verbs`, `press_level`.
- **B04 is a hash MOVER, not EQUAL** (dataclass field and class names are inside `World.content_hash()`): B04.01 (`Claim.round` to `Claim.lap`, PCR-4) and B04.07 (`Person.traits`) are encoding movers; any item in any part that renames or adds a record field is an encoding mover unless proved otherwise.
- **Conflicts the pilots met that later lanes will meet too:** a source that targets a field another item deletes (e.g. FI_D edit 2 targets R-05's `measured:` which `IS-A-01` removes in B02): do not carry the dead edit; write it in `UNDECIDED` with the reason. A `_fall` that is a fixed fraction (B22.11), a `labour` reader not yet in the tree (B22.15): write the item with a `STOPS IF` line stating the tree condition, not a guess.
- **`IS-MB-05`'s risk:** it expects fought battles at every seed once B22 closes, but B22.29 stops `march` forming in a realm with no war; the batch that closes B22 states the expected reading per seed, honestly.
- **Singletons to carry as pointers, not copies:** `towns_occupied` (B22.30) and `places_occupied` (B23) both stamp the class `Occupied`: B23's matching item is a POINTER to B22.30.

**Per-lane additions to the prompt.** Every author lane also: (1) writes `UNDECIDED:` and `DIALS AT CONTROL:` and `IDS:` lines in each batch block as the pilots did; (2) ends its receipt with the position count per batch (the head parts need it); (3) never retypes a proposal beyond the item budget; (4) uses the glossary words (A-98; MB lexicon: unit, army formation, unit formation, no company/battalion/regiment; 'lap' for the season's round; 'round' for a fight; 'riposte' with code id `finalblow_riposte`).

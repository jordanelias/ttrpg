## 12. The names (generated by `names.py` and `t13.py`)

**How it was made.** Two sources in every item, in landing order (the schedule's step, then the structure's row order, then the position table): (a) each `- NAMES:` line's `` `old` → `new` `` pairs (a rename the item makes or applies; `V12_STRUCTURE_part2.md` §5.10's table, completed from the parts); (b) each `NEW` mark followed by a backticked name in any field but `DEPENDS ON`, `SOURCE` and `GLOSSARY` (there a `NEW` cites another item's creation or a glossary row). `NEW` marks the **one** name after it: in "NEW `a`, `b`" the second name is an existing one the item edits (read at B05.10, B05.14, B05.17, where the list form is used both ways); a first run that took every name of the list as new produced eight false "introduced twice" flags, all of that kind. `S/` is read as `engine/season/`.

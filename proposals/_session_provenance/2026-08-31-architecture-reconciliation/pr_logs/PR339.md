## 1. What the PR is, in 5 sentences

PR #339 is a clean-slate, PROPOSED-but-explicitly-held-back design suite (`proposals/2026-08-28-greenfield-systems-suite/`) that rebuilds character generation, world population, personnel management, faction actions, faction management, places/settlements, settlement management, and their necessary "adjacent" systems (succession, units, the deliberative body, the wrapper layer) as a five-level hierarchy (GAME → SCALE ⟂ TIER → SUBSYSTEM → MODULE → state/keys/remit/view) composed over exactly **four stored primitives** (Entity, Tag, Post, Gauge) plus two stateless engine extensions (`derive_ob`, a disclosure-block contract). It states one write rule — every write terminates at a Gauge deposit, a Tag append, or a Post grant/revoke; entities are immutable after creation and no aggregate is ever written — as `propagation_spec_v1` AU-1 made structural. It executes two named rulings, ED-IN-0201 (the leader gate + the decider-as-option-set-gate) and ED-IN-0200 (centralized hierarchical module/key contracts), and names five explicit open rulings it refuses to guess at (Q-1..Q-5). It is held back from ratification-on-merge in full under the ED-1094 exception — merging it files the directory but flips no `## Status:` line and proposes no deletions under `systems/`. It was superseded the very next day (2026-08-29) by PR #340's `ARCHIVED.md`, which records a read-only adversarial critique finding six structural failures (two of them design *errors*, not omissions) against sixteen requirements, and a v2 suite was begun same-day.

## 3. THE FOUR PRIMITIVES — named exactly, with their full definitions quoted, and their declared operations

Named in `00_INDEX.md` §2 and fully specified in `01_substrate_primitives.md`.

### P-1 — Entity
> "One identity primitive with **declared kinds**. A person, a place, a faction, a unit and a relation are the same shape: an id, a kind, immutable identity fields declared per kind, and ownership of gauges, tags and posts."

```
Entity
├── entity_id  : str
├── kind       : person | place | faction | unit | edge      ← closed at five
├── identity   : {…}    immutable after creation; the field set is declared per kind
├── gauges     : {gauge_id: Gauge}
├── tags       : [Tag]
└── posts      : [post_id]      for kinds that site or hold posts
```
Operations: created at load or by generation; **never written afterward** (01 §1). Kind `person` carries `identity(person)` with `name, origin_node, convictions [(name,weight)], capability {attribute_key:int}, capability_provenance`. Kind `edge` is itself an entity (not a field), with `endpoints (entity_id, entity_id)` ordered, `relation: patron|client|kin|peer|rival|sworn` (closed at six), and a `disposition` gauge (−5…+5, geometric decay to rest 0).

### P-2 — Tag
> "Durable, discrete memory on **any** entity."

```
Tag
├── owner_ref     : (entity_kind, entity_id)   person | faction | place | post | edge
├── kind          : Precedent | Grudge | Debt | Reputation | Leverage      ← closed at five
├── key           : str          what specifically; the dedupe axis
├── value         : float
├── created_season: int
├── ttl           : int | None   None = durable; durable tags survive succession
└── provenance    : key_id       REQUIRED, NON-EMPTY — the Key that caused this tag
```
Operations: `tag_append` — dedupes on `(owner_ref, kind, key)` and refreshes in place; provenance required and non-empty (a tag cannot be appended without it). Swept at the accounting boundary except durable (`ttl=None`) tags, which survive sweeps and succession.

### P-3 — Post
> "The delegation object. Acting *on behalf of* something at a scale requires a post that can be granted and revoked; acting *within* is a claim on someone else's."

```
Post
├── post_id       : str
├── kind          : head | governor | minister | commander | envoy | clerk   ← closed at six
├── tier_node     : place/tier node id where this post has authority
├── principal     : faction_id | post_id      who granted it, and who may revoke it
├── holder_id     : person_id | None          None = VACANT, and a vacancy is first-class
├── remit         : [module_id]               the option set this post unlocks
├── granted_season: int | None
├── term          : int | None                None = at pleasure
└── budget        : Gauge                     (P-4) — action count per season
```
Operations: `post_grant` / `post_revoke` only. `holder_id = None` is a first-class, queryable state (a demand signal). Custody (controlling a holder without deposing them) is expressed as a `Leverage` Tag, not a field.

### P-4 — Gauge
> "Every continuous quantity in the game. A Key is a typed one-shot emission — exactly right for a flag, structurally wrong for a value that is read continuously between emissions and decays."

```
Gauge   (declared in references/descriptor_registry.yaml; instantiated per owner)
├── gauge_id   : str
├── owner_ref  : (entity_kind, entity_id)
├── scale      : one of the runtime four
├── floor, ceiling : float
├── lambda     : float in (0, 1]     the geometric decay coefficient
├── rest       : float               the value it decays toward
├── bands      : [(threshold, label)]  what the player is shown (E-2)
└── history    : [(season, delta, provenance_key_id)]
```
API: exactly three functions — `gauge_deposit(gauge, delta, provenance)` (provenance required; appends), `gauge_value(gauge, season)`, `gauge_band(gauge, season)`. **There is no setter.** Decay law: `value(t+1) = rest + (value(t) − rest)·(1 − λ) + Σ deposits(t)` — geometric, never a saturating additive step; fixed point `rest + a/λ` for bounded per-season accrual `a`, finite for every `λ > 0`.

### The two engine extensions (store nothing)
- **E-1** — `derive_ob(target_score, modifiers) -> max(OB_MIN, target_score/2.0 + modifiers)`, to live beside `roll_pool` in `engine/autoload/dice_engine.py`.
- **E-2** — a `disclosure:` block on every state row: `{of, inputs: published, presentation: band|exact, trigger: hidden}` — contract: "Publish every input. Publish a band, never a number. Never publish the trigger point."

**Cut list** (`01 §8`, what was deliberately NOT made a primitive): a separate Accrual primitive (folded into Gauge), a separate Standing/rank primitive (folded into Gauge), `custodian_id` as a field on Post (folded into Tag), a `role` string on Person (rejected — posts is derived), a Compact tag family (rejected — `Debt(recurs=True)`), a second resolver of any kind (rejected — one engine, several entry points), a View primitive (rejected as a primitive — disclosure is a declaration on state, not a store).

- **The wrapper's W-3 rule (fan-out is one Key with N targets) vs W-4 rule (stat_deltas empty on aggregate targets)** are two halves of one anti-double-write discipline, cross-referenced from three separate documents (01§7, 06§7.1, 09§4.4) — deliberate repetition for a single convention, not true duplication, but the suite itself flags this convention as *not* a resolution of the general Q-5 hazard, only a local containment.

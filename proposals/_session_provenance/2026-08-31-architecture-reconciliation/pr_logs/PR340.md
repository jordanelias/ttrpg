## 1. What the PR is, in 5 sentences

PR #340 is a two-part commit series: it first archives the v1 greenfield systems suite in place (marking `proposals/2026-08-28-greenfield-systems-suite/` superseded via banners on all eleven v1 files plus a new `ARCHIVED.md`, after a read-only adversarial pass found six structural failures, five absences, four partials and one pass against sixteen design requirements), then authors an entirely new 20-file, ~11,900-line v2 suite at `proposals/2026-08-29-greenfield-systems-suite-v2/`. v2 keeps v1's four stored primitives (Entity, Tag, Post, Gauge) and one-write-rule discipline but adds a fifth mutable `form` bucket on Entity (a fourth write leaf: the gated form transition), and ships seven named changes (A–G) fixing v1's root causes: A) split identity from form so places/people can grow and decline, B) a Project/Ambition composition so entities can want something over time, C) faction ethos+divergence so institutions can betray their own purpose, D) the Slate (an attention-budget/salience layer) so volume doesn't reach the player raw, E) an open per-kind edge registry (adopting canon's PP-724 taxonomy) so relationships aren't one flat enum, F) caste/heritage/presences as first-class setting mechanics, and G) exogenous world events so the world has an "outside." The suite is explicitly PROPOSED and held back from ratification-on-merge, is declared "reference not mechanism" under CLAUDE.md §0.05, front-loads two constraints (an "elegance criterion" and a hard "playing-surface budget" — single-digit player verbs) that shape every downstream document, and closes with a dependency-ordered 13-phase build order (13_handoff_build_order.md) that states plainly the whole suite is still DOC-class — zero executable bytes moved.

## 3. THE PRIMITIVES of v2 — named exactly, definitions quoted, operations listed; DELTA vs v1

**v1's four primitives** (per `00_INDEX.md §0`, `ARCHIVED.md`): Entity (identity **and** form both immutable — this was the root-cause-A ERROR: `place.kind` and `person.capability` were baked into unwritable identity), Tag (six kinds: Precedent·Grudge·Debt·Reputation·Leverage·Memory), Post, Gauge — one write rule with **three** leaves (Gauge deposit / Tag append / Post grant-revoke).

**v2's roster** (`00_INDEX.md §4.1`, table "P-1..P-4"):

| # | Primitive | Stores | Written by | Class |
|---|---|---|---|---|
| P-1 | **Entity** | kinds `person·place·faction·unit·edge·bloc` (**six**, `bloc` new); an id, a kind, **immutable identity**, a **mutable `form`** | created at load/generation; identity never written; form only via declared transition | substrate |
| P-2 | **Tag** | `(owner, kind, key, value, ttl, provenance)`; kinds `Precedent·Grudge·Debt·Reputation·Leverage·Holding·Ambition` (**seven** — `Memory` drafted then CUT for `Holding`, O-6 in `01`; `Ambition` added, O-A1 in `09`) | `tag_append`; provenance required non-empty, dedupes on `(owner,kind,key)` | substrate |
| P-3 | **Post** | kind (`head\|governor\|minister\|commander\|envoy\|clerk`, closed at six), tier_node, principal, holder_id (None=vacant), remit, term, `budget: Gauge` | `post_grant`/`post_revoke` only | substrate (holder's option set is surface) |
| P-4 | **Gauge** | bounded, continuously-read, geometrically-decaying value; `owner_ref` incl. edge and bloc | `gauge_deposit(delta, provenance)` — **no setter** | substrate (its band is routinely surfaced) |

Plus two engine extensions that store nothing: **E-1** `derive_ob` (obstacle derivation, single-owned, beside `roll_pool` in `engine/autoload/dice_engine.py`) and **E-2** a `disclosure:` block on every state row.

**The one write rule (v2), `00_INDEX.md §4.2` / `01 §2.1`:**
> Every write terminates at exactly one of: 1. a Gauge deposit · 2. a Tag append · 3. a Post grant/revoke · 4. a **form transition**.
> Identity is still never written. No aggregate is ever written.

**DELTA vs v1's four primitives, itemized:**
1. **Entity gains a `form` bucket** (change A) — the fourth write leaf. A form transition is a declared `references/form_registry.yaml` row: `gate` (predicate, never a roll), `cost`, `emits: form.transitioned` (always, a crossing fact never a forecast), and — if `reversible: true` — a **required** hysteresis band (`θ↑ − θ↓ ≥ H_MIN(gauge)`, `dwell ≥ 1`).
2. **Entity kind count 5→6**: `bloc` added (`06 §3`, change C — the object between "faction" and "post"; membership is a **derivation**, never stored — v3 fix, C-8).
3. **Tag enum 6→7**: `Memory` (v2 draft) cut for the ruled **`Holding`** grammar (O-6, `01 §3.1`) — a `prop_id`+stance+confidence+support_refs object that can carry *what* is misremembered, which `key`+`value` cannot; then **`Ambition`** added (O-A1, `09 §2.1`) for project intent — the enum closes again at seven, sorting into three families: institutional record (5), first-person belief (Holding), first-person intent (Ambition).
4. **Write-rule leaves 3→4**: the form transition, argued as narrower not wider than the other three.
5. **`derive_ob`** (E-1) is new: a single-owned obstacle derivation `max(OB_MIN, target_score/2 + modifiers)`, plus a whole new "commensurability gate" (`01 §6.1`) checking that a target's scale is reachable by the pool that rolls against it — the suite's own worst-defect class ("a mechanic that looks live and is dead").
6. **Disclosure contract** (E-2) formalized as a registry field, not documentation: publish every input, publish a band never a number, never publish the trigger — with the caste gate as the suite's one ruled exception (input published in full).
7. **The edge container** is redesigned wholesale: v1 had a closed six-member `relation` enum with a `disposition` Gauge on every edge; v2 **cuts that and its own v2 draft eight-kind table**, superseding both with canon's PP-724 six NPC↔NPC edge kinds (sworn-bond, liege-vassal, kinship, patronage, rivalry, feud) plus three suite-added extensions (treaty faction↔faction, charter faction↔place, allegiance person↔faction) — a shared container, per-kind semantics, NPC↔NPC disposition **derived** not stored (O-3 in `01`, catching a v1 AU-1 violation).
8. **The subsystem wrapper** is reframed from v1's "distributor" to a **herald** (O-5 in `01`): it publishes what it already computes, decides nothing, routes nothing — `targets[]` is the whole distribution mechanism.
9. **Budget**: v1 had a faction-scale action-point pool; v2 makes it **per-post** (`01 §5.3`, `05 §2`) — "one budget point buys one attempt at one module, never a modifier."

## 5. THE FOUR LATER-REINVENTED MECHANISMS

PR #344 (per the task brief) later found that four mechanisms in this v2 suite were uncited by later work and therefore re-invented. This section gives each mechanism in full: data shape, writer, reader, tick timing, and refusals — quoted and cited precisely, so a diff against the re-invention is possible.

### 5.1 World events — the actorless event channel (`11_world_events.md`)

**What it is, in one sentence (11 §1):** it is `external_shock`, "made mechanical for the first time" — the term `governance_play_redesign_v1.md:154`'s pressure homeostat names (`Π_next = clamp(Π + Σ(unserved Needs) + Σ(active Grudges) + Σ(NPC ambitions in motion) + external_shock − …, 0, 10)`) but which "has never been defined by anything on disk."

**Data shape — the event row schema (11 §2), field for field:**
```yaml
event: <id>                          # = 05's `action:` field, renamed for readability
family: Opportunity | Crisis          # the Slate's deck grammar (adopted, not invented)
origin: exogenous                     # THE ONE genuinely new field on the existing card shape
scope: place | faction                # never "world" — the top-tier place node IS world scope
remit_kinds: []                       # ALWAYS empty — DELTA 1 vs an actor's 05 row: no post holds it
triggers:                             # = 05's gate half — state predicates, ALL must hold, never rolled
  - <predicate over identity, form, gauge band, or tag existence>
hazard_pool: <int>                    # DELTA 2 — stands in for an actor's attr[a]+attr[b]+POOL_BASE;
                                       # the event's own fixed severity pool, bounded 6..18 (§5.6's bar)
resilience:                           # = 05's `ob_site` block, renamed
  target_score: <gauge id>            # what derive_ob reads — the DEFENDER's score
  modifiers: <terrain/season adjustment — a property of THIS target in THIS instance>
  M_max: <number>                     # REQUIRED — 01 §6.1.1's commensurability-gate obligation
cooldown: <int seasons, ≥ 1>          # REQUIRED — rate bound in place of an actor's post.budget
excludes: [<event id>, …]             # mutually exclusive this season, at this target
durability_bp: <int>                  # candidate-contract realized-state term
identity_touch_bp: <int>              # candidate-contract realized-state term
mandatory: <bool>                     # default false
deposits:                              # = 05's `effects:` — leaves 1-2 ONLY (gauge_deposit / tag_append),
                                       # never 3 or 4 (no post grant/revoke, no form transition directly)
  overwhelming: [...]   success: [...]   partial: [...]   failure: []   # TOTAL over 4 bands (P0-3)
follow_on:                             # a Tag, never a scheduled Key — J-N compliance
  on_fire: {tag: Precedent, key: "we_cooldown:<event>:<target>", ttl: <cooldown>}
emits: world.event_fired               # blocked on P0-1
```

**Who writes it:** nothing "writes" a world event as an object — it is a **registry row**, authored content (`references/content_registry.yaml`'s `world_events:` block), not runtime state. What the *roll* writes, per band, is exactly leaves 1-2 of the one write rule: a `gauge_deposit` on a **place-** or **faction-**owned gauge (never a form field directly — "it deposits into the gauge an EXISTING transition's gate reads, and that transition fires on its own"), or a `tag_append` (Precedent/Grudge/Debt/Reputation). ### 5.2 Ambitions and arcs — the carrier and derived-at-read `progress` (`09_ambitions_and_arcs.md` + part2)

**The carrier, exactly (09 §2, table + §2.1):** a Project/Ambition is **not** a new stored primitive. It is a composition:

| part of a project | primitive it is |
|---|---|
| the intent, target, terms, horizon | a **Tag** on the owner — `kind: Ambition` (7th tag kind, `01 §3.1`'s own two-part test run and passed at `09 §2.1`), `key: (project_kind_id, bindings)`, `ttl: horizon`, `provenance` required |
| who owns it / who it targets | ownership = the tag's `owner_ref`; targets are entity ids in its `value` payload, or **edges** where the binding is relational |
| progress toward it | **derived at read**, nothing stored |
| what advances/fires/does | a **registry row** on the project kind, in `references/content_registry.yaml` (an arc-vector TEMPLATE per the ratified `narrative_engine_design_v2_churn.md`) |
| the residue when it ends | a **Precedent** Tag |
| what it costs to declare | one point of the owner's post **budget** Gauge |

**Ambition tag literal shape:** `owner_ref = the declaring entity; kind = Ambition; key = (project_kind_id, bindings); value = target+terms; ttl = horizon (None permitted only for ratchet kinds); provenance = the declaring Key, required non-empty`.

**`progress` — the derivation, exactly (09 §3.1), and why it is NOT stored (O-A2):**
```
progress(P, season) = Σ_i  w_i · [ term_i holds at season ]           # integer basis points
threshold(P)        = declared on the project kind's row
```
Seven closed term kinds a `term_i` may read: gauge band, form value, tag existence, **tag age** (added — `season − tag.created_season` against a declared window; needed to make the ratified COLLISION arc shape expressible, since two grievances 3 seasons apart vs 30 seasons apart must read differently), post holder, edge state, season index. **`01 §5.2`'s own draft had a `progress` Gauge row — CUT** (O-A2): "a stored progress is an aggregate over the project's advance terms, and no aggregate is ever written (AU-1)." This is explicitly flagged as diverging from `references/module_contracts.yaml:343`'s own **canonical** contract, which stores project progress as a monotone 0→10 **clock** (`bucket: clock, writable: true`) — O-A2b names this a "storage divergence, recorded rather than hidden," and states the ratchet case (§3.2) reproduces canon's number exactly regardless of which write leaf backs it.

**Monotone counters need no exemption (§3.2):** a "ratchet term" is `[a durable Tag with key K exists on the owner]`. Since tags are append-only and durable tags (`ttl: None`) survive sweeps and succession, "a ratchet term, once true, is true forever — monotonicity by construction, not by carve-out." No second decay law, no `λ=0` gauge. The worked case reproduces canon's Löwenritter coup counter exactly: `advance_terms: [{w:1, term: "tag(owner, Precedent, key=failure_mark.*) exists"}]`, `threshold: 3`, `fire: {guaranteed: true, at: accounting_boundary}`, `horizon: null`.

**Who writes it:** `am.declare` (the ONE surface verb, `01 §2.1` leaf 2 tag append) creates the Ambition tag; `am.advance` (resolver `derivation`, `state: []` — "a derivation owns no state, this row is empty on purpose") reads and recomputes `progress`, writing nothing; `am.fire` (resolver `gate`, never a roll — "the uncertainty was in getting the state there, and re-rolling at the threshold charges for it twice") applies the declared consequence, terminal; `am.lapse` (resolver `gate`) drops the tag on horizon/stall/unreachability, leaving a Precedent residue.

**Who reads it:** `10`'s Slate (every `am.*` emission is a candidate, gathered by `sl.candidates`); `07`'s `place_found` transition (gated on a `founding_claim` Precedent tag deposited by a project's fire effect — verb-free by design); `05`'s `act.charter` (gated on `bloc.state==in-schism` and a `founding_claim` tag, per `06`'s schism seam).

**When it ticks:** `am.advance`/`fire`/`lapse` are **never invoked by a post** — the herald runs them at the boundary, reading state, consuming nothing (`consumes: []` on all four modules — explicit J-N compliance: "it advances because the world IS a certain way at the accounting boundary. It reads state").

**Obstruction — the mechanism that makes it not a timer (§5):** "advance is a read of world state. So any act that moves a term a project reads obstructs it — with **no obstruct verb, no obstruct module, and no knowledge of the project at all**." `supporters`/`obstructors` are derived AT FIRE by walking `causes[]` for the terms that moved — not accumulated, not stored.

**What it refuses:** a stored progress Gauge (O-A2); three new key types (O-A3 — 3 of 4 already registered under ED-935; only `state.project_formed` was genuinely missing, adopted from an existing gap-audit proposal G-29 verbatim); an `am.obstruct` verb ("the document's best cut"); an `am.abandon`/`am.reprioritise` verb (redundant with letting `ttl` lapse / declaring a different project); a runtime-mutable `threshold` (static registry field only — a "successor kind," not a re-armable threshold, is how escalation is expressed); a `pl.revolt` verb or unrest row elsewhere in `11` (§6.4's place-bound auto-declaration supplies the mass-actor case with zero new verb/module/budget/key-type instead).

**§6.4's place-bound auto-declaration — the suite's one truly actorless project ("rising"):** a project kind whose `owner_binding.entity_kind` is `place` **AUTO-DECLARES at the accounting boundary** for every place whose gate holds, and **LAPSES** when it stops — invoked via the SAME `am.declare` module, herald-run with `remit:[]` and `budget:null` (a place has no post, no budget gauge). This is a genuinely reversible pair (declare/undeclare), so — unlike every other project (whose fire is terminal and needs no hysteresis) — a place-bound kind is the **one place in the document where a hysteresis band is required** on the `owner_binding.gate` itself.

### 5.3 The slate and salience — how anything is put in front of a decider (`10_the_slate_and_salience.md` + part2)

**What it is (10 §1.1):** "the Slate is how a deep world reaches a player through a small surface. It is the only object in v2 that is wholly surface, and it is the reason every other object in v2 can be substrate." It does not design a salience function — it explicitly binds to and specifies the seam around the already-**ratified** Light Function (`narrative_engine_design_v2_churn.md §4`, ED-IN-0011), which it re-attacks term by term and keeps entire (§0.1).

**The candidate — the whole deliverable, field for field (10 §2.1):**
```yaml
candidate:
  candidate_id:   <deterministic hash; H(emitter‖kind‖anchor‖sorted(subject_refs)‖provenance)>
  emitter:        <module id that produced it>          # e.g. sm.business, am.advance, we.fire
  kind:           <row id in references/content_registry.yaml>
  anchor:         <entity_id>            # the place, faction or person the situation IS AT
  scale:          personal | settlement | territory | peninsula
  subject_refs:   [<entity_id>, ...]     # sorted; everything the situation is ABOUT
  durability_bp:      <int>   # how long its consequence persists, in accountings
  identity_touch_bp:  <int>   # whether it bears on a subject's identity/convictions
  # tie_proximity_bp is NOT supplied by the emitter — it is derived
  horizon:        {band: <int>, foreclosure_in: <int|null>}  # forecast term; governs DEPTH never ENTRY
  informational:  <bool>                 # default false. True ⇒ news: no resolver, no responses
  resolver_ref:   <module id | null>     # the ONE module that resolves this at either fidelity
  responses:      [<3..5 response ids from resolver_ref's declared option set>]
  mandatory:      <bool>
  witness:        {channel: chronicle|witness_key|document_key|post_remit|co_located, ref: <id>}
  provenance:     <key_id>               # REQUIRED, non-empty — the Key that caused this
  disclosure_ref: <state id>
```
**It is derived, never stored — an emitter RETURNS it at the accounting boundary; it is never a Key.** "A candidate is not a stored object … not an entity … not authored content … not a subsystem" (10 §2.3).

**Who writes it:** every emitter across the whole suite — `sm.business` (08), `am.advance/fire/lapse` (09), `we.fire` (11), `fa.*` (05/06), `pm.vacancy/tenure` (04), `substrate.form` (01, form transitions as `informational: true` crossing-fact candidates), plus canon's own Duty/Conviction/Outreach scans and mandatory/world-state trigger sets — all conform to the ONE contract (C-1..C-6): provenance required, witness required, realized-state-terms only, `resolver_ref` names an existing dual-fidelity module, `responses` drawn (never invented) from that module's own set, and — the load-bearing rule — "an emitter emits; it never presents, ranks, or checks the budget."

**Who reads it:** the Slate's own four modules — `sl.candidates` (gathers, `class:surface`, resolver `derivation`), `sl.cast` (the P-08 knowability gate, resolver `gate`), `sl.rank` (computes `cast_score`/`depth_score`, resolver `derivation`), `sl.truncate` (top-n selection to the scene budget, emits `slate.item_surfaced`). **All four declare `state: []`** — the anti-distributor falsifier is explicit: "if a future version of this document gives an `sl.*` module a `state:` row … that version has built the prohibited thing."

**Ordering — cast_score decides entry, depth_score decides render depth only, never entry (§4):**
```
cast_score(c)  = meaningfulness(c) × inertia(c) × scale_weight(c.scale)
meaningfulness = durability_bp × tie_proximity_bp(derived) × identity_touch_bp
depth_score(c) = cast_score(c) × forecast_mass(c) × imminence(c.horizon.band)
```
Casting is severed from forecast by construction — this is what prevents a "forecast a revolt → surface it → player acts → forecast strengthens" rubber-band loop.

**When it ticks — inertia derived, never carried (§7, resolving a J-N conflict with the ratified text):** the ratified Light Function describes inertia as "a persistent priority term whose carryover decays" — a **carried** value, which `01 pt2 §9.3` proves the substrate cannot do (no cross-season carry). 10 resolves this by **deriving** the identical arithmetic from the append-only Key log instead of storing/carrying it:
```
last_lit(c)   = the accounting_index of the most recent slate.item_surfaced Key with this candidate_id
d             = t − last_lit(c)
inertia_bp(c) = INERTIA_NEUTRAL                                    if none
              = INERTIA_NEUTRAL + INERTIA_BASE · NUM^d // DEN^d    otherwise
```
"Nothing is posted to next season's Slate; next season's Slate re-derives everything, including how much attention this thing already had." (A v3 fix corrected a genuine bootstrap-deadlock defect where the baseline had been `0` instead of `INERTIA_NEUTRAL`, which multiplicatively zeroed every never-lit candidate's score on every campaign's season 1.)

**What it refuses:** a second scoring function beside the ratified Light Function (considered, declined, argued term-by-term at §0.1); a novelty term (the ratified term is the *opposite* shape — inertia); anything the player did last season outside inertia/tie-proximity (double-counting); any relational term above `01 §3.4`'s cap; a Memory-tag inertia-log fallback (v2.0 had one; cut in v3 because it would have violated the Slate's own "writes nothing" contract).

### 5.4 The act economy (declared not-a-mechanism; the suite's actual attention/action-economy split)

There is no single "act economy" object in v2 — the suite deliberately splits what a v1-style act economy would have been into two orthogonal, already-covered mechanisms rather than building a fourth: **`post.budget`** (`01 §5.3` — "one budget point buys one attempt at one module, never a modifier," per-post not per-faction, so a faction's total capacity is the sum over the posts it actually staffs) governs **what an actor may attempt**; **the Slate's scene budget `A`/`B`** (`10 §1.2`, ratified canon numbers, not this suite's to retune) governs **what reaches the player's attention at all**. `00 §4.3` change **D** names this split explicitly as the fix for v1's root cause D ("an action economy with no attention economy … budgets govern what an actor may do; nothing governs what reaches the player"). Per `00 §4.3`: "D is the only change that is pure distillation, and it is the one that pays for the other six … **Ship D or do not ship the rest.**" If a later document reinvented "the act economy," the two halves to check it against are `01 §5.3` (spend) and `10 §5.1`'s truncation algorithm (attention).

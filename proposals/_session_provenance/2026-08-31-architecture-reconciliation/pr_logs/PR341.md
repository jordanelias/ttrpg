## 1. What the PR is, in 5 sentences

PR #341 is a read-only adversarial critique of the v2 greenfield systems suite
(`proposals/2026-08-29-greenfield-systems-suite-v2/`, PR #340, 18 files), run as nine independent Fable 5
critics — one per throughline (T1–T9) — each using the `valoria-critic` agent definition (Read/Grep/Glob
only, structurally read-only), instructed to steelman the suite's answer before attacking it. A tenth,
synthesising pass (the session that authored this PR) performed independent verification by reading —
not grepping — the working-tree code the critics cited, corrected five of the nine critics' claims, and
produced a cross-cutting register (X-1..X-8) of findings independently rediscovered by two or more
critics. The central result is a single named architectural gap — "the strategic World has no
personal-scale actor layer" — that the PR argues explains four separate honest engine stubs
(`mc_v18.py` NPC generation, `mc_v18.py` knot formation, `combat_bridge.py`'s faction-only Combatant,
`scene_dispatch.py`'s deferred combat/contest actor derivation) and is exactly what the v2 suite's docs
01–04 build without ever citing those stub sites as the reason. Verdicts: zero SUPPORTED, two
STRUCTURALLY BLOCKED (T2 beliefs, T3 fallibility), seven PARTIAL, zero ABSENT. The PR touches no engine,
systems/, or tools/ code — it adds exactly six markdown documents under
`proposals/2026-08-29-fable5-throughline-critique/` and is explicitly reference-only under CLAUDE.md
§0.05 (deleting it would not change how the game behaves).

## 10. The independent-verification method (from `05_independent_verification.md`)

**Method rule (§1), quoted:** *"Jordan, this session: grep, regex and glob are used to LOCATE and FIND,
but not to CONCLUDE."* A match count, empty result, or pattern hit is "a pointer to a place that must
then be opened and read" — binding hardest on negatives ("nothing writes this", "no caller exists",
"zero references"), because a pattern's silence is evidence about the pattern, not about the tree.
Before concluding a negative, ask what the pattern would MISS: an alias, a dict write, a generic setter,
a value passed positionally, a key built at runtime, a differently-spelled synonym, or a string-resolved
call through `composition.require`.

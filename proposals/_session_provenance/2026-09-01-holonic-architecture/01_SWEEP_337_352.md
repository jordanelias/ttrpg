## The arc, in six phases

**1 · Measure (#337, #338).** The line opens with collation, not design. #337's headline: Valoria is
not under-designed but **disconnected** — 15% of classified things are correct code with no caller, and
every lane asked for a writer or a loader rather than a new mechanic. #338 names the organising
distinction in embryo: acting *on behalf of* a faction needs a delegation object; acting *within* it
needs a position object; **both were named and neither ran.**

**2 · Greenfield, and its collapse (#339 → #340 → #341).** Eight systems on four stored primitives,
archived the same day by its own adversarial pass over six structural failures — *"the write rule
forbade identity changes, so settlements could not grow."* Nine read-only critics over v2 then found
**zero SUPPORTED throughlines**, with the organising finding that **the strategic world has no
personal-scale actor layer.** Retracted here: the `Entity/Tag/Gauge/Post` primitive set as a
foundation.

**3 · From scratch, then tested (#342, #343, #344).** One actor, two relations, faction-as-proposition,
`choose` without a `World`. Tested against 56 NPC seasons and 83 arcs, collapsed into one superseding
document. The review then found the vocabulary **could not create or transfer anything** — five
existence operations, all decider-free. ⚠ **That review's own flagship was refuted inside itself**
(committing to an uttered proposition *is* founding).

**4 · Reconciliation (#345) and the throughlines (#346/#347/#349).** #345 is the first PR to point
review at code and registries rather than at other proposals. Its central ruling splits a false
dichotomy: **the Key substrate IS the Event mechanism and is NOT the Claim/witness/Query mechanism** —
*"the line between the halves is one docstring."* It also carries a table titled ***"the tree the
design line never read"***, whose holonic-doctrine row reads *"in tension with 'containment is an
edge'"* — **the tension this session's proposal finally adjudicates.** #346 was reverted by #347 and
re-landed by #349.

**5 · The unified shape (#350).** Re-adjudicates #345 with lanes that read code and run it. Lands the
asymmetric Partition as a schema column, the moral-layer ruling (Belief is moral, not epistemic), and
eighteen adjudication rows including **R-2 (compose Event onto the log, never a second log)** and
**R-3 (the six steps refine a coarser tick).**

**6 · Execution and its audit (#351, #352).** #351 implements the shape faithfully enough to run,
drives it with 78 blind-authored cases, adds the **Edge Law (L5)**, promotes `Record` to a carrier, and
proposes an act budget. #352 then shows **the case layer never executed at all** — verdicts are keyword
lookups, and one misplaced classifier file in `cases/` reuses all 50 arc ids and flips ~40 verdicts.
Removing it reproduces the committed results **byte-identically**. #352 also **retracts four of its own
charges** after adversarial review, and the decisive control it had failed to run made the verdict
*more* favourable to #351.

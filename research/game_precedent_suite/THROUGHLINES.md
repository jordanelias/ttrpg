# Throughlines, templates and primitive equivalences across the precedent suite

## Status: FILED - reference, not canon (CLAUDE.md §0.05) - tier 3 - resolves nothing at runtime
## Date: 2026-10-22 · Lane: IN (cross-cutting) · Written against `51d7b05`
## What changes in engine/season/: nothing.

**What this is.** A cross-reading of `tables/` (R1..R9, R3a, R3b), `tutorials/` (T01..T19) and `dispositions/` (D_T01..D_T10 and the `_also` files). It names the smallest mechanical elements (primitives) the roughly seventy games are built from, groups games that build the same primitive under different names (equivalence classes), names recurring compositions of primitives (templates), and names the design questions the suite keeps returning to (throughlines). The vocabulary is derived from the capability ids A1..M5 and from the tutorials' loop and choice-menu sections, not from a prior list. If this file were deleted the game would behave identically.

**How to read it.** A cite is `R#:line` or `T##:line` into this directory and carries the tag grade the cited cell gives (`[V2]`, `[V3]`, `[S2]`, `[S3]`, `[M]`, `[CONTESTED]`, `?`); URLs are left in the cited file. The Valoria column is taken only from the dispositions' HAS and DIFFERS rows and cited as `D_T##:line (#row)` with the code cite exactly as that row gives it (`es/` and `ES/` are the dispositions' abbreviations). Status is this file's reading of those rows: **HAS** = a row shows the primitive running; **PARTIAL** = the rows show it in part, only in tests (TESTS-ONLY), at a control value that makes it inert, or with a changed owner or cadence; **LACKS** = no HAS/DIFFERS row carries it, or the rows record its absence (often by a ruling or an axiom). Nothing here was re-verified against a game or the Valoria code, and nothing here is a work item.

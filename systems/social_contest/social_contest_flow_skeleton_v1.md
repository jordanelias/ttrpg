## 3. Flow

**S1. Build (the ADAPTER — `build_contest`).** `[gate]`
  S1.1 Coerce `side_a`/`side_b` into kernel `Contestant`s. `systems/social_contest/sim/contest/wrapper.py:115 _as_contestant`
  S1.2 Resolve `venue`: a named proceeding string looks up `PROCEEDINGS`, builds the `Venue` via `proceeding_venue`, and reads `adjudicator`/`track_start` off the spec; a prebuilt `Venue` object is passed through unchanged. `systems/social_contest/sim/contest/wrapper.py:118-135 build_contest`
  S1.3 `[branch]` Resolve the adjudicator: explicit type name → `CANONICAL_ADJUDICATORS[type]()`; explicit prebuilt object → used as-is; `None` → the proceeding's canonical default. `systems/social_contest/sim/contest/wrapper.py:138-150 build_contest`
  S1.4 `[branch]` **ED-137 Panel closure**: if the resolved adjudicator type is `"panel"`, rebuild the venue's win-condition to `panel_win_condition(...)` (a terminal per-member `VoteAtClose` ballot), replacing whatever win-condition S1.2 set. `systems/social_contest/sim/contest/wrapper.py:172-181 build_contest`
  S1.5 Derive `resistance` via `_derive_resistance(proc_name, world)` — reads `world["stabilities"]`; returns `None` when `world` is falsy/not a dict, `0` when no proceeding, `0` when the proceeding has no tracker. `systems/social_contest/sim/contest/wrapper.py:42-55 _derive_resistance`
  S1.6 Return a `Contest` (adapter output — resolves nothing). `systems/social_contest/sim/contest/wrapper.py:183-186 build_contest`

**S2. Resolve (the ROUTER — `resolve_contest`).** `[gate]`
  S2.1 `[branch]` Look up `GAMES[game]`; raise on an unknown game name. `systems/social_contest/sim/contest/wrapper.py:241-242 resolve_contest`
  S2.2 Resolve `policy_a`/`policy_b` from `POLICIES` if given as strings. `systems/social_contest/sim/contest/wrapper.py:243-244 resolve_contest`
  S2.3 `[branch]` `game="agon"` → `_resolve_agon`, which constructs a `Bout` from `contest.side_a/side_b/venue/adjudicator` (no `armature=` passed — see §7) and calls `bout.resolve(policy_a, policy_b)`. `systems/social_contest/sim/contest/wrapper.py:193-198 _resolve_agon`
  S2.3.1 `[branch]` `game` ∈ `{consensus, negotiation, inquiry}` → a registered `stubwire.stub_resolve` STUB row; returns a bare `StubResult`, not the `((winner,reason), bout)` tuple. `systems/social_contest/sim/contest/wrapper.py:201-226 _stub`

**S3. The exchange loop (`Bout.resolve`).** `[loop]`
  S3.1 For `i` in `range(venue.budget)`: for each `side` in `(A, B)`:
    S3.1.1 Build a `ContestView` (`Bout._view`) and hand it to that side's policy callable to get a `Move`. `systems/social_contest/sim/contest/resolver.py:258-267 _view`, `systems/social_contest/sim/contest/resolver.py:425 resolve`
    S3.1.2 `[gate]` `Bout._apply(side, mv)` validates `mv.kind` against `VALID_KINDS`, raising on an unrecognized kind. `systems/social_contest/sim/contest/resolver.py:323-324 _apply`
    S3.1.3 `[write]` Unconditionally spends the reserve for `mv.kind` before dispatching on it. `systems/social_contest/sim/contest/resolver.py:330 _apply`
    S3.1.4 `[branch]` Dispatches on `mv.kind` ∈ `{pass, hard, support, shift, evidence, rebut, advance}`:
      — `pass` / insufficient reserve → a fault (`yields`). `systems/social_contest/sim/contest/resolver.py:326-329 _apply`
      — `support` → refills reserve, builds ethos. `systems/social_contest/sim/contest/resolver.py:331-332 _apply`
      — `shift` → reframes the live stasis ground upward, or faults (`contradicted`) on an illegal reframe. `systems/social_contest/sim/contest/resolver.py:333-339 _apply`
      — `evidence` → presents the best unpresented relevant `EvidenceItem` (hidden value, no roll) via `_advance(readiness=False, build=False)`. `systems/social_contest/sim/contest/resolver.py:340-347 _apply`
      — `rebut` → gated by `venue.allow_rebuttal` (default `False`); on a landed reception, erases opponent advancement up to a cap. `systems/social_contest/sim/contest/resolver.py:348-355 _apply`
      — `advance` / `hard` → gated by `SelfGating.licit` and `Stasis.relevant`; on pass, computes `pool_bonus`/`dsigma_bonus` from `self.armature` (only non-zero when a `Bout` was constructed with `armature=`) and calls `_reception` → `_advance`. `systems/social_contest/sim/contest/resolver.py:356-389 _apply`
      S3.1.4.1 `[branch]` `[gate]` CR5 self-Face backfire: only fires when `self.armature is not None and self.armature.cr5`, on a `deg==0` Obscuring foul. `systems/social_contest/sim/contest/resolver.py:404-419 _apply`
    S3.1.5 `[gate]` After each move: `venue.faults.check(...)` — a hit ends the bout immediately (`clinch:<reason>`). `systems/social_contest/sim/contest/resolver.py:438-442 resolve`
    S3.2 `[gate]` After both sides move in exchange `i`: `venue.win.resolve(state, closing=False)` — a non-`None` result ends the bout (`"win"`). `systems/social_contest/sim/contest/resolver.py:443-445 resolve`
  S3.3 After the budget is exhausted: `venue.win.resolve(state, closing=True)` — the terminal band/verdict. `systems/social_contest/sim/contest/resolver.py:446-447 resolve`

**S4. Verdict.** Returns `(winner_or_band, reason)` where `reason` ∈ `{"win", "draw", "clinch:<detail>"}`; for `"agon"`, `resolve_contest` returns `((winner, reason), bout)`. `systems/social_contest/sim/contest/resolver.py:421-447 resolve`, `systems/social_contest/sim/contest/wrapper.py:194-198 _resolve_agon`

**S5. `[emit]` Optional beat log.** `Bout(record=True)` accumulates a per-move beat dict into `self.log`; `record` defaults to `False` and IS plumbed through the wrapper — `resolve_contest`'s own `record=False` keyword forwards unchanged into `GAMES[game]["resolve"](...)`, which for `game="agon"` is `_resolve_agon`, which forwards it into `Bout(..., record=record)`; this path is exercised at `systems/social_contest/sim/contest/_kernel_tests.py:676 _golden_trace` (`record=True`). The one production seam, `engine/cross_scale/scene_dispatch.py:299`, never passes `record=True`, so on that seam the wrapper's own default keeps the log empty; it is otherwise populated when a caller passes `record=True` through the wrapper or builds a `Bout` directly (`agon_harness.py`, `faction.py`). `systems/social_contest/sim/contest/resolver.py:245 Bout`, `systems/social_contest/sim/contest/resolver.py:426-437 resolve`; plumbing confirmed at `systems/social_contest/sim/contest/wrapper.py:197 _resolve_agon`, `systems/social_contest/sim/contest/wrapper.py:245 resolve_contest`; production non-use confirmed at `engine/cross_scale/scene_dispatch.py:299 _resolve_slot`.

**S6. `[emit]` Narrative summary (dormant).** `narrative.summarize(log, winner, why)` turns a beat log into a `Chronicle`; it is a pure consumer of S5's log and is never called outside `_kernel_tests.py` and `agon_harness.py` (itself uncalled — see §7). `systems/social_contest/sim/contest/narrative.py:112 summarize`

**S7. `[branch]` The scene-dispatch seam (`scene_dispatch._resolve_slot`, `st == "contest"`).**
  S7.0 `[gate]` The whole `st == "contest"` branch (S7.1-S7.4 below) runs inside `_resolve_slot`'s single `try`; any exception it raises is caught and converted to an unresolved scene (`out["reason"] = f"resolver raised: {e!r}"`) rather than propagating — see §7 for the risk this masks. `engine/cross_scale/scene_dispatch.py:223 _resolve_slot`, `engine/cross_scale/scene_dispatch.py:372-374 _resolve_slot`
  S7.1 `[gate]` Derive `parts` from `ctx["parties"]`, or — for `stakes["kind"]=="emergency_council"` — from `_emergency_council_parties(faction, world)` (reads `Faction.L`/`Faction.Sta`); defers (no resolution) if fewer than 2 parts. `engine/cross_scale/scene_dispatch.py:277-284 _resolve_slot`, `engine/cross_scale/scene_dispatch.py:120-138 _emergency_council_parties`
  S7.2 Reseed the global `random` stream from `rng.getrandbits(32)`, call `build_contest(parts[0], parts[1], venue=proceeding)` (no `world=`, no `armature=`) then `resolve_contest(built)`, then restore the prior global random state. `proceeding` defaults to `EMERGENCY_COUNCIL_PROCEEDING` ("guild_arbitration"), whose adjudicator is `panel` (§2), so S1.4's Panel-closure branch fires unconditionally here and the PersuasionTrack win-condition (S1.2's default) is unreached on this seam — see §7. `engine/cross_scale/scene_dispatch.py:288-301 _resolve_slot`
  S7.3 `[write]` `[branch]` For `emergency_council` stakes only: set `ctx["echo"] = {actor_faction, target_faction, most_relevant_stat="L", degree}` keyed off the verdict side. `engine/cross_scale/scene_dispatch.py:334-343 _resolve_slot`
  S7.4 `[gate]` `[branch]` If `world.echo_scheduler` is set (ECHO_TRANSPORT on), route `ctx["echo"]` through `echo_transport.emit_scene_echo` → a queued `domain_echoes` entry (`fires_at: "accounting"`); otherwise `zoom_out({})` — no echo. `engine/cross_scale/scene_dispatch.py:386-397 _resolve_slot`, `engine/cross_scale/zoom_in_out.py:135-136 zoom_out`

  S8.5 `[branch]` Independently (not gated on S8.2's outcome) attempt `_run_transfer_motion` → `parliamentary_transfer.propose_transfer` — fires both on the normal path after the vote resolves (S8.3/S8.4) and on the `_derive_vote`-returned-`None` early-return path (fewer than two eligible factions still runs a Transfer motion). `engine/cross_scale/parliamentary_bridge.py:165-177 _run_transfer_motion`, `engine/cross_scale/parliamentary_bridge.py:194 run_parliamentary_scene`, `engine/cross_scale/parliamentary_bridge.py:217 run_parliamentary_scene`
